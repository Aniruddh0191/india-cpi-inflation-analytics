# Data Sources

## CPI dataset
The project uses the All India CPI dataset supplied for the project, with monthly observations from January 2013 through May 2023. Preserve the original publisher attribution and terms when redistributing the source data.

## Imported crude oil
The imported-oil analysis uses monthly Indian Basket crude-oil prices from India’s Petroleum Planning & Analysis Cell (PPAC).

- PPAC official website: https://ppac.gov.in/
- Navigate to the international crude-oil prices / Indian Basket data section for the source series.

If you have the exact original download URL for the CPI CSV, add it here before publishing.
