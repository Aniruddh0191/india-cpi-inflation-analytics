# Data Dictionary

| Field | Description |
|---|---|
| Sector | Rural, Urban or Rural+Urban reporting sector |
| Year | Calendar year of the observation |
| Month | Month name |
| Date | First day of the observation month, used for time modelling |
| CPI category columns | CPI index values for the listed category |
| General index | General CPI index |

CPI values are index values, not direct currency prices. Missing values represent unavailable or invalid observations and should not automatically be interpreted as zero. The Q3 food-category table and Q5 correlation table are stored in long format for category-level analysis.
